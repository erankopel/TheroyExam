# הדרך ל־26 – גרסת תצוגה (v2)

מאגר זה **אינו מכיל קוד של האפליקציה**. הוא רק מפרסם עותק מסומן של הענף `claude/v2-explanations` מהמאגר [erankopel/TheroyExam](https://github.com/erankopel/TheroyExam) בכתובת נפרדת, כדי לראות ולנסות את גרסה 2 בלי לגעת באתר הרגיל.

**הכתובת:** https://erankopel.github.io/TheroyExam-preview/

- בראש כל מסך מופיע תג כתום "גרסת תצוגה" עם קוד הקומיט שמוצג.
- ההתקדמות, ההגדרות והתמונות השמורות כאן **נפרדות לחלוטין** מהאתר הרגיל (כתובת אחרת = אחסון אחר בדפדפן), ולכן אפשר לשחק בחופשיות.
- העמוד מסומן כ־noindex ולא ייכנס לתוצאות חיפוש.
- אם מתקינים את האפליקציה ממנו למסך הבית, היא תופיע בשם "26 תצוגה".

## הפעלה חד־פעמית

1. **Settings → Pages → Build and deployment → Source → GitHub Actions**.
2. **Actions → Publish v2 preview → Run workflow**. אחרי כדקה האתר באוויר.

## איך הוא מתעדכן

- **אוטומטית:** בכל שעה נבדק אם יש קומיט חדש בענף, ורק אז מפרסמים מחדש.
- **ידנית:** Actions → Publish v2 preview → Run workflow. אפשר לכתוב שם ענף אחר ולהציג אותו.
- אם אין פעילות במאגר 60 יום, GitHub מכבה את הבדיקה השעתית; מספיק להריץ ידנית פעם אחת כדי להדליק אותה מחדש.

## מעבר לאתר הרגיל

תצוגה בלבד. כדי להעלות את גרסה 2 לאתר הרגיל (`eva.medicom.vip`), ממזגים את `claude/v2-explanations` לענף ברירת המחדל של המאגר המקורי. התצוגה לא משנה דבר באתר הרגיל.
