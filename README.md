# הדרך ל־26 – הכנה למבחן התיאוריה

אפליקציית לימוד (PWA) למבחן התיאוריה לנהיגה, המבוססת על **מאגר השאלות והתשובות הרשמי של משרד התחבורה** – כל 1,802 השאלות עם כל התמונות.
אתר סטטי לחלוטין: בלי שרת, בלי בסיס נתונים ובלי מעקב. ההתקדמות נשמרת בדפדפן של הלומד/ת.

## מה יש בפנים

| | |
|---|---|
| **לימוד לפי יחידות** | כל נושא (חוקי התנועה, תמרורים, בטיחות, הכרת הרכב) מחולק ליחידות קצרות עם איור, פס התקדמות ו"כללים חשובים" מהמאגר |
| **תרגול חכם** | משוב מיידי, שאלות שנפלו חוזרות בסוף הסבב, ערבוב סדר תשובות, הקראה קולית |
| **הסברים לשאלות** | אחרי כל תשובה מופיע הסבר קצר למה התשובה נכונה (פתוח אחרי טעות, סגור אחרי תשובה נכונה), גם ברשימת הטעויות ובתוצאות מבחן הדמה. ההסברים לא רשמיים: נכתבו על בסיס המאגר, נבדקו מול התמונות ומול חוק התנועה, ובמקרה של סתירה המאגר הרשמי קובע |
| **חזרה מרווחת** | שיטת לייטנר: שאלה שנענתה נכון חוזרת אחרי יום, 3, שבוע, שבועיים, חודש. טעות מחזירה אותה לתחילת המחזור |
| **מבחן דמה** | כמו המבחן האמיתי: 30 שאלות, 40 דקות, 26 נכונות לעבור. בלי משוב עד הסוף, ניווט בין שאלות, סימון שאלות, ניתוח טעויות. יש גם "מבחן ממוקד" שמדגיש חולשות |
| **מילון תמרורים** | כל תמרור וסימון דרך מהמאגר עם המשמעות; מצב כרטיסיות (ניחוש) וחידון |
| **מדד מוכנות** | ציון צפוי וסיכוי משוער לעבור, לפי מה שנלמד עד כה ולפי מבחני הדמה האחרונים, ותוכנית לימוד (שאלות חדשות ביום) אם קבעו תאריך מבחן |
| **התקדמות** | מפת פעילות, רצף ימים, מבחני דמה לאורך זמן, יחידות חלשות, שאלות קשות, תגים, שיתוף סיכום להורים |
| **מחברת חזרה + חיפוש** | טעויות, שאלות שמחכות לחזרה, שאלות מסומנות, חיפוש בכל המאגר |
| **PWA** | מתקינים על מסך הבית, עובד גם בלי אינטרנט, מצב כהה, הגדלת טקסט |
| **כל סוגי הרישיון** | B (ברירת מחדל), A, C1, C, D, 1 – מסנן את השאלות הרלוונטיות |

## פרסום ב־GitHub Pages (בחשבון שלכם)

לא צריך טוקן, מפתח פריסה (deploy key) או סודות. ה־workflow משתמש ב־`GITHUB_TOKEN` המובנה עם ההרשאות שהוגדרו בקובץ עצמו. צריך **פעולה אחת בהגדרות המאגר**:

1. במאגר: **Settings → Pages → Build and deployment → Source → GitHub Actions** (ולא "Deploy from a branch").
2. אם המאגר פרטי: Pages בחשבון חינמי עובד רק במאגר ציבורי (Settings → General → Danger Zone → Change visibility), או בחשבון בתשלום.
3. **Actions → Deploy to GitHub Pages → Run workflow** (או דחיפה חדשה). זהו.

הפריסה רצה בכל דחיפה לענף ברירת המחדל של המאגר (בדחיפה ראשונה למאגר ריק זה הענף שנדחף ראשון; אפשר לשנות שם ל־`main` ב־Settings → General → Default branch). בענפים אחרים רצות רק הבדיקות.
כל עוד Pages לא הופעל, שלב הפריסה מסתיים באזהרה (ולא בשגיאה) עם הוראה מה לעשות.
הכתובת: `https://<המשתמש>.github.io/<שם-המאגר>/`

**דומיין משלכם:** באותו מסך (Pages → Custom domain) מזינים למשל `theory.example.com`.
   - תת־דומיין: ב־DNS יוצרים רשומת `CNAME` שמצביעה אל `<המשתמש>.github.io`.
   - דומיין ראשי (apex): רשומות `A` אל `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
   - מסמנים **Enforce HTTPS** (נדרש כדי שהתקנה כאפליקציה ומצב לא־מקוון יעבדו).
   - אפשר גם להוסיף קובץ `CNAME` בשורש המאגר עם שם הדומיין בלבד.

כל הנתיבים באתר יחסיים, כך שהוא עובד גם בכתובת עם תת־נתיב (`/TheroyExam/`) וגם בשורש הדומיין.

### חלופות אירוח (אותו אתר סטטי, בלי שינוי בקוד)
- **Cloudflare Pages** – חיבור למאגר, Build command ריק, Output directory `/` (או להריץ קודם `python3 tools/build_sw.py`).
- **Netlify / Vercel** – גרירת התיקייה או חיבור למאגר; ללא build.
- **שרת משלכם** – מעתיקים את הקבצים (`index.html`, `sw.js`, `manifest.webmanifest`, `css/`, `js/`, `fonts/`, `img/`, `data/questions.json`, `data/units.json`) לכל שרת סטטי עם HTTPS.

## פיתוח מקומי

```bash
python3 -m http.server 8000        # או: npx http-server .
# http://localhost:8000
node --test tests/*.test.mjs       # בדיקות יחידה (חזרה מרווחת, הערכת מוכנות, גיבוי)
python3 tools/validate_data.py     # בדיקות שלמות למאגר
```

בדיקות דפדפן (Playwright, השרת המקומי על פורט 8123):

```bash
NODE_PATH=$(npm root -g) node tests/e2e/flow.mjs <תיקיית-צילומים>   # זרימה מלאה: לימוד, תרגול, מבחן, כל המסכים
NODE_PATH=$(npm root -g) node tests/e2e/explain.mjs                  # כרטיס ההסבר: מצב בהיר וכהה, נגישות

```

## עדכון המאגר

משרד התחבורה מעדכן את המאגר מדי פעם. כדי להתעדכן:

```bash
# 1. מחליפים את tools/source/TheoryExamHE-DATA.csv בקובץ החדש
python3 tools/parse_csv.py     # CSV -> data/questions_raw.json
# 2. מורידים תמונות חדשות אל img/q/ (הכתובות מופיעות ב-questions_raw.json)
python3 tools/build_data.py    # מיזוג עם חלוקת היחידות -> data/questions.json, data/units.json
python3 tools/validate_data.py
python3 tools/build_sw.py      # מחתים גרסה חדשה ל-service worker
```

שאלות חדשות שלא סווגו ליחידה מקבלות יחידת ברירת־מחדל של הקטגוריה שלהן; מוסיפים אותן ל־`data/classification.json`.

### גרסת תצוגה נפרדת

התיקייה `preview/` היא התוכן של מאגר נפרד (`TheroyExam-preview`) שמפרסם עותק מסומן של ענף גרסה 2 בכתובת משלו (`https://<המשתמש>.github.io/TheroyExam-preview/`), בלי לגעת באתר הרגיל ובלי לשתף איתו התקדמות שמורה. הוראות ההפעלה ב־`preview/README.md`.

### הסברים לשאלות (`data/explanations.json`)

`tools/expl_batches.py` מכין קבוצות שאלות לכתיבה. לכל קבוצה: כותב (שפותח את התמונות), בדיקת עקביות מול המאגר והתמונה, בדיקת חוק עם חיפוש ברשת, וקריאה סופית לכל טקסט שנכתב מחדש או סומן "לא בטוח". `tools/merge_explanations.py --strict` ממזג את התוצאות ובודק כללי כתיבה (בלי אותיות תשובה כי התשובות מתערבבות, ניסוח ניטרלי מבחינת מגדר, אורך), ו־`tools/validate_data.py` בודק אותם גם ב־CI. שאלות שבהן המאגר עצמו נראה לא עקבי מפורטות ב־`docs/bank-notes.md`.
